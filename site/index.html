FaTrainer

Trainers that open as a menu inside the game. One file next to the game's executable, a key to open it, nothing to install. Free and open source.

Games

Each game gets its own trainer, built for how that game works.

Every FaTrainerworks the same way.

One file

The trainer is a single DLL the game loads from its own folder. Delete it and the game is untouched.

A menu over the game

Press Insert or F8. While it is open the game ignores your mouse and keyboard.

Windows and Linux

On Linux it runs through Steam's Proton with one launch option.

Nothing leaves your PC

A trainer never connects to the internet. It only writes its settings and a log next to the game.

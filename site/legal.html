2. Terms of service

These terms are issued under Article 8 of the Polish Act of 18 July 2002 on providing services by electronic means. They are available free of charge on this page and can be saved or printed at any time.

§ 1. Definitions

  1. Website means the website at fatrainer.fatum.cc.
  2. User means anyone who uses the Website.
  3. Program means FaTrainer, a free modification for the game Dying Light in the form of the file xinput1_3.dll, offered on the Website and, with its source code, on GitHub.

§ 2. Services

  1. The provider offers two services free of charge: making the Website's content available to read, and making the Program available to download.
  2. The Website has no user accounts, no forms and no payments, and it does not publish content supplied by Users.

§ 3. Technical requirements

  1. Using the Website requires a device with internet access and a current web browser. JavaScript is not required; without it the Website works without animation.
  2. The Program works with the PC (Steam) version of Dying Light on Windows, or on Linux with the Proton compatibility layer.

§ 4. Conclusion and termination

  1. The contract for services by electronic means is concluded when the Website is opened in a browser and ends when the User leaves it. Downloading the Program creates no further obligation.
  2. The User may stop using the Website at any time, without giving a reason and at no cost.

§ 5. User obligations

  1. Users must not supply unlawful content, including in messages sent to the provider.
  2. Users must not disrupt the Website, including through overload attacks or attempts at unauthorised access.

§ 6. The Program

  1. The Program is free and licensed under the MIT License, whose text is in the project repository. Its source code is public.
  2. The Program changes how the game behaves on the User's computer. It sends no data to the provider or to anyone else; it only writes a settings file and a log (fatrainer.ini, fatrainer.log) in the game folder.
  3. The User uses the Program at their own risk and should back up their game saves first.
  4. Using the Program in the game's online modes (co-op, Be The Zombie) also changes the game for other players and may breach the rules of use set by Techland S.A. The User is responsible for any consequences for their game account.
  5. To the extent permitted by law, the provider is not liable for damage resulting from use of the Program, unless caused intentionally or through gross negligence. This does not exclude or limit any consumer rights that cannot be excluded or limited by contract.

§ 7. Trademarks

Dying Light is a trademark of Techland S.A. The Program and the Website are an independent fan project and are not made, supported or endorsed by Techland S.A. The game's name is used only to say which game the Program works with.

§ 8. Complaints

  1. Complaints about the Website or the Program can be sent to the provider's e-mail address in section 1.
  2. A complaint should include contact details and a description of the problem. For Program errors, the fatrainer.log file helps.

4. Cookies and similar technologies

The Website stores no cookies or other data on your device (for example in localStorage), so it does not ask for consent.

The one exception can be the __cf_bm cookie, which Cloudflare sets for about 30 minutes when it needs to tell automated traffic from people. It is strictly necessary to secure the Website, so under Article 399 of the Polish Electronic Communications Law of 12 July 2024 it needs no consent. You can delete and block cookies in your browser settings.
